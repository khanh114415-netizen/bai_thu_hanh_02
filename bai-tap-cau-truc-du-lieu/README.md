# Bài tập môn Cấu trúc dữ liệu và Giải thuật

Kho lưu bài tập C theo từng thư mục. Mỗi bài nên có mã nguồn `main.c`, sơ đồ khối `flowchart.png` và README ghi đề bài, ý tưởng, cách biên dịch/chạy, cùng ví dụ nếu phù hợp.

## Danh sách bài

| Thư mục | Nội dung |
|---|---|
| `bai_01_mang_so_thuc_bang_con_tro/` | Nhập và in mảng một chiều số thực bằng con trỏ |

## Cách đưa lên GitHub

1. Tạo một repository mới trên GitHub, ví dụ `bai-tap-cau-truc-du-lieu`.
2. Tải thư mục này lên repository hoặc đặt các tệp trong một thư mục Git đã tạo trên máy.
3. Giữ cấu trúc thư mục như bên dưới để bài và sơ đồ không bị tách rời:

```text
bai-tap-cau-truc-du-lieu/
├── bai_01_mang_so_thuc_bang_con_tro/
│   ├── main.c
│   ├── flowchart.png
│   └── README.md
└── README.md
```

4. Mở `README.md` trên GitHub để kiểm tra phần giới thiệu và mở README của bài để xem hướng dẫn riêng.

Bạn có thể tải toàn bộ thư mục `bai-tap-cau-truc-du-lieu` lên GitHub bằng nút **Add file → Upload files**, hoặc dùng GitHub Desktop để tạo commit và **Publish repository**. Đặt repository ở chế độ **Public** nếu thầy cần truy cập bằng liên kết.
